# WeightScope icon alternatives

Created with the built-in imagegen tool on 2026-10-17. Matrix Lens was selected for the extension and is used as a 256 × 256 PNG at `media/icon.png`, in the extension manifest, inspector header, and editor tab. The original concepts remain here for reference.

Open `preview.html` in a browser to compare each original at 256, 128, 64, and 32 pixels. The PNGs are the full-resolution generated originals.

## 01-matrix-lens

Asset: `01-matrix-lens.png`

Final prompt:

```text
Use case: logo-brand.
Asset type: standalone square icon concept for WeightScope, a VS Code extension for locally inspecting machine-learning model weights, tensor health, and checkpoint differences.
Create exactly ONE finished icon, no presentation board. Flat, precise geometric brand mark suitable for a developer tool, strong silhouette and generous negative space, readable at 32 and 64 pixels. Center the mark and let it occupy about 65% of the square. Full-bleed solid deep navy background #10151e, warm peach #eab087 as the primary mark color, mint #7fc6b3 as a restrained secondary accent only when useful. Use clean edges and deliberate consistent geometry. No typography, letters printed as text, numbers, captions, border labels, watermarks, mockup, scenery, photographic texture, heavy shadows, glow, 3D bevels, or fine circuitry. Keep the design simple and distinctive.
Primary request: Design an elegant inspection-lens symbol. A bold peach circular magnifying lens with a short diagonal handle pointing down-right encloses a sparse two-by-two matrix of four mint rounded square cells, with ample space between cells and ring. Integrate the components into a single balanced compact mark. The ring should feel like a precision instrument; the matrix should communicate model weights. Minimal, confident, flat.
```
